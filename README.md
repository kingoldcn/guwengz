# 古文观止 · 青少年图文读本

> 观止，观止，最好的古文都在这里。

清人吴楚材、吴调侯编选的《古文观止》，精选先秦至明代 222 篇传世名作。本项目将其制作成适合中小学生阅读的图文读本：每篇都有注音、逐句译文、生词注释和赏析导读，并配有 AI 绘本插画。

## ✨ 特色功能

- **📚 全本 222 篇** — 完整收录 12 卷原文，从春秋到明代，一脉相承
- **🔤 全文注音** — 生僻字标注拼音，扫清阅读障碍
- **📖 逐句译文** — 文白对照，逐句翻译，便于理解
- **🎨 AI 绘本插画** — 每篇配有精美插画，图文并茂
- **🎓 分级学习** — 小学、初中、高中三级难度，按需选读
- **📅 历史长河** — 按时代检索，串联两千年文学史
- **⭐ 名句金句** — 精选传世名句，随时品读
- **👤 作者墙** — 认识历代文豪大家
- **📊 阅读进度** — 本地保存阅读记录和收藏，跟踪学习进度
- **🔍 全文搜索** — 快速定位篇目

## 🚀 快速开始

本项目为纯静态网页，无需构建，直接打开 `index.html` 即可阅读。

### 本地预览

```bash
# 方式一：直接双击 index.html 打开

# 方式二：使用本地服务器（推荐）
# Python
python -m http.server 8000

# Node.js
npx serve .
```

然后访问 `http://localhost:8000` 即可。

### 部署到 GitHub Pages

1. 将代码推送到 GitHub 仓库
2. 在仓库 Settings → Pages 中，选择 `main` 分支的根目录
3. 稍等片刻即可通过 `https://<username>.github.io/<repo>/` 访问

## 📝 关于《古文观止》

《古文观止》是清代吴楚材、吴调侯叔侄编选的古代散文选本，成书于康熙三十三年（1694 年）。全书共 12 卷，收录自东周至明代的散文 222 篇，以散文为主，兼取骈文。书名"观止"取自《左传》中季札观乐"叹为观止"之意，意指所选皆为古文精华。
